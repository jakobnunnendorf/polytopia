Explained by Claude (sonnet) on 2026-11-25. The snippet:

```ocaml
(* rl-02_value-iteration.ml *)
(* EMAI in Polytopia, Reinforcement Learning, Week 02 *)
(* Jakob Nunnendorf, 25 Nov 2026 *)

let the_map =
  [| "..FFF..V";
     "..FFF.M.";
     "....F...";
     ".M......";
     "..~~...F";
     "...~~..." |];;

let width = String.length the_map.(0)
and height = Array.length the_map;;

let village = (7, 0);;
```

- `(* ... *)`: This is OCaml's block comment syntax, used instead of `#` or `//`. Comments can span multiple lines and can be nested.
- `let the_map = ...`: A top-level `let` binds a name to a value, like an assignment, but the binding is immutable and no type annotation is needed because types are inferred.
- `[| ...; ... |]`: This is an array literal, with elements separated by semicolons rather than commas. Without the `|` bars, `[ ... ]` would be an immutable linked list.
- `;;`: This ends a top-level phrase, telling the compiler that the expression is complete. In compiled files it is often optional, but it is common in notes and in the interactive toplevel.
- `String.length the_map.(0)`: Function application is written by juxtaposition, with no parentheses or commas, so this calls `String.length` on the argument. The `.( )` syntax indexes an array, so `the_map.(0)` is the first row, and `String.length` is a function named `length` inside the `String` module.
- `let ... and ...`: `and` joins several bindings into one `let` so they are defined simultaneously. Neither binding can refer to the other, which is why `height` does not use `width`.
- `(7, 0)`: This is a tuple, written with commas inside parentheses. Its type is `int * int`, and it is a fixed-size, immutable group of values.
