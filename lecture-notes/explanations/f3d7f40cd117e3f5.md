Explained by Claude (sonnet) on 2026-11-25. The snippet:

```ocaml
type terrain = Field | Forest | Mountain | Water | Village;;

let terrain_at (x, y) =
  match String.get the_map.(y) x with
  | '.' -> Field
  | 'F' -> Forest
  | 'M' -> Mountain
  | '~' -> Water
  | 'V' -> Village
  | _   -> assert false;;

let () = assert (terrain_at village = Village);;
```

- `type terrain = Field | Forest | ...`: Declares a variant type (like a TypeScript union of literal tags or a Python enum). Each name is a constructor, and constructors must start with a capital letter.
- `;;`: Optional terminator that ends a top-level phrase. It is mainly needed in the interactive toplevel, and otherwise just marks where a definition ends.
- `let terrain_at (x, y) =`: Defines a function with `let`, with no `def` or `return`. The parameter `(x, y)` is a tuple pattern, so the function takes one pair and unpacks it, and the body's value is the result.
- `match ... with | '.' -> Field | ...`: Pattern matching, a switch that selects a branch by the shape or value of the expression. Each `| pattern -> result` is one case, and the first case that matches is used.
- `String.get the_map.(y) x`: `String.get` is a function in the `String` module, called by juxtaposition: `String.get s i` rather than `String.get(s, i)`. The `.( )` in `the_map.(y)` is array indexing, so this gets row `y` and then character `x` from it.
- `_`: Wildcard pattern that matches anything and binds nothing, so it acts as the default case.
- `assert false`: `assert` checks a condition and raises an exception if it is false. With `false` it always raises, marking a case that should be unreachable.
- `let () = assert (terrain_at village = Village);;`: `let () =` matches the result against `()`, the unit value (like `None` or `void`), which is the idiom for running a side-effecting expression at top level. Here `=` inside the parentheses is structural equality, not assignment.
