1 · How one decision is made

Every fighting action of the learner's units goes through this loop; the greedy champion plays everything that spends or earns stars before and after it. One value function V is shared by all units; each unit evaluates it from its own view.

2 · Real decisions, step by step

Decisions recorded in the analysis games with the current weights. Each row is one candidate action: the reward it earns now, V of the unit before and after it, and the gain = reward + V after − V before. The highest gain is played if it is above 0, otherwise the units pass. Click a row to see which features moved V.

4 · Which features matter

Permutation importance: how much worse V predicts the returns when one feature is shuffled across samples (rise in squared error, stars²). For the linear model also the signed weight × one standard deviation of the feature: what a typical change of that feature is worth.

6 · Learned interactions

Slices through the learned V: two features vary, all others stay at their median. A linear model can only draw tilted planes here (parallel colour bands); bands that bend or cross mean the network has learned that one feature's worth depends on the other, e.g. that high danger matters only when HP is low.
